# Kyheem Jones — Public Service Website

This is a static GitHub Pages site built around Kyheem Jones's leadership, service, education, and Philadelphia public-service story.

## Files
- `index.html` — site content
- `style.css` — responsive design
- `script.js` — mobile navigation and year

## Deploy
Replace the existing site's `index.html`, `style.css`, and `script.js` with these files in the existing GitHub Pages repository and commit the changes. GitHub Pages will publish the updated files from the repository.

## Notes
This version intentionally presents a future public-service identity rather than claiming an active mayoral campaign. It can later be expanded into a formal campaign site.
